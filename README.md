# Discover Mannar — HTML, CSS & JavaScript starter

A responsive, static tourism discovery website for Mannar District, Northern Province, Sri Lanka.

## Run locally
1. Extract the ZIP.
2. Open the `discover-mannar-frontend` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Select a destination card to open its details page.

No Python, Flask, MySQL, npm or build step is needed.

## Features
- Responsive landing page
- 12 Mannar District attractions
- Search by destination, area or category
- Category filters: Beach, Wildlife, Nature and Heritage
- Individual destination detail pages
- Google Maps search links
- Mobile navigation menu

## Edit destination data
All destination content is in `js/places.js`. Each place has an ID, name, category, area, description, highlights, visitor notes, image and map search query.

## Important content notes
- The destination list and introductory information are based on the Northern Province Tourism destination directory, Sri Lanka Tourism, and Mannar District public-sector information.
- Opening hours, entrance fees, access restrictions, road conditions and wildlife sightings can change. Confirm them with the relevant authority or local operator before travelling.
- The remote Unsplash images are illustrative placeholders, not verified photographs of the named Mannar attractions. Replace them with your own licensed/permissioned photographs before public launch.
- Google Maps links use place-name searches rather than verified fixed pins. Review each result and replace with a confirmed pin if needed.
- Adam’s Bridge is a sensitive marine and cultural landscape. The site does not imply that visitors can cross it; follow all local restrictions and safety guidance.
